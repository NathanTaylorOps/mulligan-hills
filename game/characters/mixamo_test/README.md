# mixamo_test

Drop the 5 Mixamo test FBX files here (see `## For Nathan` in `docs/phase0/animation.md`).

- `upload/golfer_placeholder_tpose.obj` is the placeholder golfer as a T-pose OBJ, generated by
  `python3 tools/animation/make_golfer_gltf.py --obj`. It is what you upload to Mixamo if you
  choose to test the placeholder instead of a Mixamo default character.
- Do not commit Mixamo files to a public repository until `docs/LICENSE_LEDGER.md` says raw
  redistribution is allowed (the Mixamo FAQ is silent on it).
