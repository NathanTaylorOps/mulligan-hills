# Phase 0 archive index

The files in this directory are **historical technical-risk proof notes** from the initial project setup.

They are preserved because they contain useful reasoning, old test plans and early feasibility work, but they are not current project instructions.

For current project truth, use:

- [Architecture](../ARCHITECTURE.md)
- [Status](../STATUS.md)
- [Decisions](../DECISIONS.md)
- [Verification](../VERIFICATION.md)
- [Quality gates](../QUALITY_GATES.md)
- [Development](../DEVELOPMENT.md)

Statements such as "NOT YET RUN", old workstream ownership, early device assumptions and Gate 0 branch rules describe the historical checkpoint in which each file was written. They should not be interpreted as the current state of the repository.

Current implementation and exact-SHA evidence always take precedence.
