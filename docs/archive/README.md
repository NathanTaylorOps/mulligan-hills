# Documentation archive

This directory preserves superseded decisions, process notes, handovers and investigation records for traceability.

Archived material is **not current project guidance**.

Use the current documents at docs/README.md first. Historical documents may contain:

- obsolete branch names;
- old workstream/agent ownership;
- assumptions that were later verified or rejected;
- superseded product scope;
- historical test results tied to older commits.

Do not copy an archived claim into current documentation without re-verifying it against current source, decisions and evidence.
