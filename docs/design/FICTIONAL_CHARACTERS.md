# Fictional character direction

Mulligan Hills should use **original fictional characters** for release content.

## Character strategy

Characters may be built from broad archetypes such as:

- elite touring professional;
- veteran course architect;
- eccentric entertainer;
- obsessive equipment collector;
- local club legend;
- ambitious junior;
- high-profile business visitor;
- touring musician;
- comedy superfan.

Recognition should come from Mulligan Hills' own writing, silhouettes, clothing language, equipment, carts, habits and recurring stories — not from a renamed or visually imitated real person.

## Release rules

- Do not use a real person's name as a design dependency.
- Do not copy a recognisable likeness, signature outfit, logo, vehicle livery, voice, lyric, catchphrase or personal incident.
- Avoid jokes that imply factual misconduct, injury or private behavior by an identifiable real person.
- Real-world golfers/celebrities may be used as private market/reference research, but public character specifications should be original.
- Any licensed guest would require a separate explicit licensing path.

## Production model

Use a shared procedural/modular character system with:

- body/height ranges;
- face/hair archetypes;
- wardrobe families;
- equipment themes;
- cart themes;
- animation/gesture sets;
- personality tags;
- visit/challenge/story hooks.

Validate a small representative roster first. Scale content only after the system proves readable, performant and fun.
