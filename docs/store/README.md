# Store and release readiness

This folder contains **release-operations material**, not authoritative gameplay architecture.

Use it when preparing a specific release candidate. Store policies, console fields and legal requirements change, so every submission must be checked against the current store consoles and primary documentation.

## Contents

- listing drafts for Google Play and App Store;
- data-safety/privacy-label working notes;
- content-rating notes;
- trademark/name-clearance checklist;
- release checklist;
- privacy/terms drafts requiring professional review;
- current release questions.

## Rules

1. Store copy may claim only features present in the release candidate.
2. Legal/privacy drafts are not publication-ready until reviewed for the actual publisher, regions and live data flows.
3. Data-safety answers must match the shipping binary and backend, not an earlier plan.
4. Pricing, tester requirements and policy thresholds must be verified in the current console.
5. Personal contact/recruitment operations do not belong in the public-facing engineering narrative.
6. Final release evidence belongs with the release candidate, not as a permanent claim that policies will never change.

Current unresolved release choices are in [open_questions.md](open_questions.md).
